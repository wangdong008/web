# 智捷数码科技 · 个人导航页

单页手机导航站，包含常用链接导航、搜索、实时时钟、定位天气、音乐播放等功能。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构（引用下面两个文件） |
| `style.css` | 全部样式 |
| `script.js` | 全部交互脚本 |
| `README.md` | 本说明 |

> 部署时把这 4 个文件放在同一目录即可，`index.html` 会自动加载 `style.css` 和 `script.js`。

## 功能

- **链接导航**：14 个常用网址，点文字或蓝色胶囊即可展开；复制、修改（标题/网址/简介一次改完）。
- **自动简介**：未手动编辑的条目，根据网址自动填充默认说明。
- **搜索栏**：输入即时过滤本站链接；回车或点「百度」走百度搜索。
- **实时时钟**：月日 + 星期 + 时分秒，每 5 秒刷新。
- **定位天气**：自动定位显示城市、温度、天气（Open-Meteo + BigDataCloud，免 Key）。
- **分享**：点 📤 调起系统分享面板，分享 https://wd.xhihi.art 。
- **深浅色切换**：右上角 ☀️ / 🌙。
- **音乐播放**：右下角悬浮按钮，5 首背景音乐。

## 部署（Cloudflare Pages）

1. 把本目录 4 个文件传到同一目录。
2. Cloudflare Pages → Upload assets → 拖入文件夹。
3. Framework preset 选 None，Build 命令留空。

## 注意

- 定位天气需要 HTTPS 环境（Cloudflare Pages 默认就是）。
- 数据存在浏览器 localStorage，修改过的内容不会同步到服务器。
